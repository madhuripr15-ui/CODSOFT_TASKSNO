 # CodSoft Data Analytics Internship

## Project Overview
This repository contains my data analytics internship tasks completed as part of the CodSoft Data Analytics Internship.

## Tasks Completed

### Task 1: Data Cleaning
- Cleaned a sales dataset.
- Handled missing values and duplicate records.
- Standardized data and prepared it for analysis.

### Task 2: Exploratory Data Analysis (EDA)
- Analyzed sales by product and region.
- Explored quantities, prices, and potential outliers.
- Summarized key findings from the dataset.

### Task 3: Data Visualization
- Created charts to explore and present sales data.
- Used bar charts, line charts, pie charts, histograms, and scatter plots.

### Task 4: Customer Segmentation
- Analyzed a sample customer dataset.
- Grouped customers by spending and age.
- Summarized spending by customer segment and location.

## Tools Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Project Note
The datasets used in this project are sample datasets for learning and analysis.
